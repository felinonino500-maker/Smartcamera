Persiapan & Update Repositori Termux

Pastikan Anda menggunakan Termux versi terbaru dari F-Droid atau GitHub (bukan Play Store).

Langkah pertama adalah memperbarui paket bawaan, mengizinkan akses penyimpanan internal HP, dan menginstal utilitas dasar seperti git, curl, dan nodejs.

bash — setup-dasar.sh 
# 1. Update dan upgrade paket sistem
pkg update -y && pkg upgrade -y

# 2. Berikan izin akses storage HP (klik Allow pada popup)
termux-setup-storage

# 3. Install paket esensial (Git, Curl, Nano, Node.js, OpenSSL)
pkg install -y git curl wget nano nodejs-lts openssl-tool

Setup OpenSSH Server (Remote dari Laptop)

Mengetik kode di layar HP kadang melelahkan. Gunakan SSH agar bisa remote dari PC/Laptop dalam satu jaringan Wi-Fi.

bash — setup-ssh.sh 
# 1. Install paket OpenSSH
pkg install -y openssh

# 2. Buat password baru untuk login SSH (ketik password Anda)
passwd

# 3. Jalankan SSH daemon (Default berjalan di port 8022)
sshd

# 4. Cek Username dan IP Lokal HP Anda
echo "Username Anda: $(whoami)"
ifconfig | grep "inet " | grep -v 127.0.0.1

# 5. Cara konek dari terminal PC/Laptop:
# ssh -p 8022 USERNAME_ANDA@IP_HP_ANDA

Instalasi & Konfigurasi Gemini CLI

Jalankan asisten AI Google Gemini langsung dari terminal Termux untuk coding, debugging, atau automasi.

Prasyarat: Dapatkan API Key gratis dari Google AI Studio (aistudio.google.com) atau login langsung menggunakan akun Google Anda via CLI.
bash — setup-gemini-cli.sh 
# 1. Install Official Google Gemini CLI secara global via npm
npm install -g @google/gemini-cli

# 2. Simpan GEMINI_API_KEY secara permanen ke ~/.bashrc
# Ganti 'MASUKKAN_API_KEY_ANDA' dengan kunci dari Google AI Studio
echo 'export GEMINI_API_KEY="MASUKKAN_API_KEY_ANDA"' >> ~/.bashrc
source ~/.bashrc

# 3. Jalankan Gemini CLI interaktif
gemini

# Atau tanya langsung satu baris:
# gemini -p "Buatkan struktur folder proyek Go untuk REST API"

Instalasi Go (Golang) & Environment Path

Kompilasi binary native ARM64 super cepat langsung di ponsel Android Anda.

bash — setup-golang.sh 
# 1. Install paket Go terbaru dari repositori Termux
pkg install -y golang

# 2. Konfigurasi GOPATH dan PATH di ~/.bashrc agar binary go install terbaca
cat << 'EOF' >> ~/.bashrc
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
EOF

# 3. Terapkan konfigurasi environment
source ~/.bashrc

# 4. Verifikasi versi Go yang terpasang
go version

Integrasi Firestore & Realtime Database (RTDB)

Instalasi Firebase CLI sekaligus inisialisasi proyek Go dengan Firebase Admin SDK untuk membaca & menulis ke Firestore dan RTDB.

bash — setup-firebase.sh 
# 1. Install Firebase Tools CLI secara global
npm install -g firebase-tools

# 2. Login Firebase (Gunakan --no-localhost karena di Termux HP)
firebase login --no-localhost

# 3. Buat folder proyek Go & install Firebase Admin SDK v4
mkdir -p ~/projects/go-firebase && cd ~/projects/go-firebase
go mod init go-firebase
go get firebase.google.com/go/v4
go get google.golang.org/api/option

Simpan file kredensial dari Firebase Console (Project Settings → Service Accounts) sebagai serviceAccountKey.json di dalam folder proyek.

go — main.go 
package main

import (
	"context"
	"fmt"
	"log"

	firebase "firebase.google.com/go/v4"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	// Konfigurasi URL Realtime Database Anda
	conf := &firebase.Config{
		DatabaseURL: "https://PROJECT_ID_ANDA-default-rtdb.firebaseio.com",
	}
	opt := option.WithCredentialsFile("serviceAccountKey.json")

	// Inisialisasi Firebase App
	app, err := firebase.NewApp(ctx, conf, opt)
	if err != nil {
		log.Fatalf("Gagal inisialisasi Firebase: %v\n", err)
	}

	// --- 1. TULIS DATA KE CLOUD FIRESTORE ---
	fsClient, err := app.Firestore(ctx)
	if err != nil {
		log.Fatalf("Gagal konek Firestore: %v\n", err)
	}
	defer fsClient.Close()

	_, _, err = fsClient.Collection("termux_logs").Add(ctx, map[string]interface{}{
		"device": "Android Termux",
		"status": "Firestore Connected!",
	})
	if err != nil {
		log.Fatalf("Gagal tulis Firestore: %v", err)
	}
	fmt.Println("✅ Berhasil menulis ke Firestore!")

	// --- 2. TULIS DATA KE REALTIME DATABASE (RTDB) ---
	rtdbClient, err := app.Database(ctx)
	if err != nil {
		log.Fatalf("Gagal konek RTDB: %v\n", err)
	}

	ref := rtdbClient.NewRef("server_status/termux")
	err = ref.Set(ctx, map[string]interface{}{
		"online": true,
		"stack":  "Go + Gemini CLI + SSH",
	})
	if err != nil {
		log.Fatalf("Gagal tulis RTDB: %v", err)
	}
	fmt.Println("✅ Berhasil menulis ke Realtime Database (RTDB)!")
}
